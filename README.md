# 🌐 Dynamic Portfolio with Admin Panel

A responsive and database-driven portfolio website with a secure admin panel to manage portfolio content. This project is built using **Core PHP, MySQL, Bootstrap, JavaScript, jQuery, and AJAX**.

# ✨ Features

## 👤 User Side

- Responsive Home Page
- About Sectio
- Skills Section
- Projects Section
- Education Section
- Experience Section
- Contact Form
- Social Media Links
- Mobile Friendly Design

---

## 🔐 Admin Panel

- Secure Admin Login
- Dashboard
- Manage Skills (CRUD)
- Manage Projects (CRUD)
- Manage Education (CRUD)
- Manage Experience (CRUD)
- Manage Contact Information
- Image Upload
- Update Portfolio Content
- Logout

---
